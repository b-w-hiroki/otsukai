サイトのトップ https://otsukai.birdman-studio.com/ は紹介ページです）

## 1. まずはこれだけ — 基本の流れ

<img src="screenshots/01-home.png" width="320" alt="ホーム画面">

家族の誰かが**買ってほしいものを追加**し、買いに行ける人が**「買うよ」と宣言**して、買えたら**「買ったよ」**。それだけです。

```
① ＋ で追加   →   ② ◯タップで「買うよ」   →   ③「✅買ったよ」で完了
   （誰でも）          （買いに行く人）              （履歴に残る）
```

完了すると**ポイントがもらえ**、家族から**「ありがとう」**が届きます。

まだ何も登録していないときは、お買い物タブに🧺のキャラクターと「お買い物したいものを登録しよう！」の案内、
その下に「はじめかた」の3ステップが出ます（1件でも追加すると通常のリストに切り替わります）。

初めてメイン画面に来たとき（家族を作った・参加した直後）は、使い方とホーム画面への追加を
案内する5ステップのオンボーディングが自動で出ます。いつでも「スキップ」で閉じられ、
一度見たらそのアカウントでは二度目以降出ません（端末ではなくアカウント単位。
`users/{uid}/onboardingSeen` をRTDBに保存しており、別の端末で同じアカウントに
ログインしても再表示されません）。

最初と最後は画面中央のカードで説明しますが、間の3ステップ（＋追加ボタン／ストックタブ／
ミッションボタン）は実際のボタンを暗転の中で光らせて説明する「スポットライト」演出です
（ソシャゲのチュートリアルのような見た目）。吹き出しの「次へ」で進められるほか、
光っている本物のボタンを直接タップしても本物の操作として機能したうえで次のステップへ
進みます（例: ＋追加を光らせているステップで実際に＋追加をタップすると、本物の追加シートが
開く）。

最後のステップ（ホーム画面に追加）は端末によって内容が変わります: Android/デスクトップの
Chrome・Edge はワンタップの「ホーム画面に追加」ボタン、iOS は共有ボタンからの手順、それ以外は
ブラウザメニューを探してもらう一般案内になります（すでにホーム画面から起動している場合は
案内自体を省略）。

下のタブ（ストック・お買い物・設定）は、ボタンをタップする以外に**左右にスワイプ**しても
切り替えられます。よく買うもの・支出・家計はタブではなく、それぞれお買い物ページの
フローティングボタンとプレイヤー情報シートから開くシートです（[4章](#4--よく買うもの)・
[5章](#5--支出家計)）。ミッションもコア機能ではないため下部タブには置かず、
右上（名前と？の間）の🏆ボタンから開きます。

## 2. ⏳ そろそろ切れるかも（買い忘れ防止）

**このアプリで一番おすすめの機能です。** 買い忘れそうなものを、アプリが先回りして教えてくれます。

<img src="screenshots/02-lowstock.png" width="340" alt="そろそろ切れるかも">

お買い物タブのいちばん上に出ます。**タップするだけで買い物リストに追加**できます（× で消せます）。

### 2つの根拠から予測します

| 表示 | 意味 | どこから来る？ |
|---|---|---|
| 🔴 **切れてる** | ストックで「切れた」と記録済み | ストックタブの記録 |
| 🟡 **残り少ない** | ストックで「少ない」と記録済み | ストックタブの記録 |
| 🔄 **約7日ごと・2日超過** | いつもの購入間隔から、そろそろ買う時期 | **買い物履歴からの自動学習** |

🔄 の予測は、**同じ品を3回以上買うと自動で働きはじめます**。
「牛乳はだいたい5日で無くなる」といった家庭ごとのペースを、アプリが履歴から学びます。設定は不要です。

> 💡 **急ぎのものは赤枠**で表示され、上に「2件はもう切れています・1件は買い時を過ぎています」と内訳が出ます。
> × を押すと消せます（そのストックが動くか、次の周期に入ると、また出てきます）。

### いつから知らせるかを変えられます

<img src="screenshots/17-lowlead-setting.png" width="340" alt="知らせる時期の設定">

ストックタブの上部にある **⏳ そろそろ切れるかも → 知らせる時期** で、**何日前からお知らせするか**を選べます。

| 選ぶと | こうなります |
|---|---|
| 切れる当日に | ぎりぎりまで出さない。リストをすっきり保ちたい人向け |
| **2日前から（初期設定）** | 買い物のタイミングを逃しにくい、ちょうどよい設定 |
| 1週間前・2週間前・1か月前から | まとめ買いの人向け。次の買い出しでまとめて拾える |

- **家族で共通の設定**です（誰が変えても全員に反映されます）
- ストックが 🟡🔴 のものは「もう無い」という事実なので、**この設定に関係なくすぐ出ます**

### 品ごとに「◯日ごと」と決められます

<img src="screenshots/16-stock-cycle.png" width="320" alt="買う間隔を指定">

ストックタブで品名をタップ →「**買う間隔**」に日数を入れて保存すると、**履歴の学習より優先**されます。

- **3回買うのを待たずに**予測を効かせられます（登録したその日から）
- 学習した周期がしっくり来ないときの**上書き**にも使えます
- 起点は「最後に買った日」。履歴が無い品は「🟢 たっぷり」に戻した日が起点になります
- 空にして保存すると解除され、また履歴からの自動学習に戻ります

> 手で決めた間隔は「30日ごと」、学習した間隔は「約30日ごと」と表示され、見分けられます。

### 通知でも知らせます
毎週日曜20時のまとめ通知に「⏳ そろそろ切れそう: 米・ラップ」が付きます。
完了ゼロの週でも、切れそうなものがあれば単独でお知らせします。

## 3. 🛒 お買い物タブ

### 追加する

<img src="screenshots/03-add-sheet.png" width="320" alt="おつかいを追加">

下部のフローティングボタン列にある **＋ 追加** から追加します。品名と**カテゴリ**は必須、それ以外は任意です。

**カテゴリは🍎食品・🧻日用品・📦その他の3つから必ず1つタップします。** 選ばずに保存しようとすると
「カテゴリを選んでください」と出て進めません。当てはまるものが無ければ「📦その他」を選びます
（「未分類」という選択肢は無く、何もタップしないまま知らないうちに未分類になる、を防ぐための仕様です）。

| 項目 | 使いどころ |
|---|---|
| 📷 写真 | **どれを買ってほしいか一目で伝わる**（詰め替え用・型番違い・いつものメーカーなど）。実際に撮る/選ぶ以外に、**🎨「イラストから選ぶ」で用意した115種のイラスト（野菜・果物・肉魚・日用品・掃除など9分類）を選ぶ**こともできます |
| カテゴリ（必須） | 🍎食品 / 🧻日用品 / 📦その他 → 売り場順に並びます |
| 行き先（任意） | スーパー・薬局など、[設定タブ](#9-️-設定タブ)で登録したお店から選べます。買い物リストがカテゴリの中でさらに行き先ごとにまとまります |
| 手間 | ふつう / 💪ちょっと大変 / 💪💪めちゃ大変 → **ポイントが増えます** |
| 🔥 急ぎ | リストの最上段に固定＋ポイント+1 |
| 予算上限 | 「300円以下で」など |
| ブランド指定 | 「パナソニック」など |
| メモ | 「12ロール・ダブル」など |
| 担当者を指名 | 特定の人に頼む（その人だけに通知が届きます） |

### 📷 写真は一覧からすぐ開けます

写真を付けた品は、**リスト・履歴のどこでもサムネイルが出ます**。
右下に 🔍 が付いているので押せると分かります。**タップすると大きく表示**されます
（行そのものをタップしたときは詳細が開きます。サムネイルを押しても詳細は開きません）。

### リストの見方

<img src="screenshots/04-claimed.png" width="320" alt="買うよ宣言後">

**1行1品**で、上から順に消していけます。並び順は **🔥急ぎ → 🍎食品 → 🧻日用品 → 📦その他 → 📎未分類**。売り場を回る順に消せます。
行き先を1つでも使っていると、**カテゴリの中がさらに行き先ごとにまとまります**（急ぎはすぐ買うものなので行き先では分けません）。

| 操作 | 動き |
|---|---|
| **◯ を1回タップ** | 「買うよ」宣言 → 宣言済みリストへ移動 |
| **◯ をもう一度タップ** | 「買うよ」を取り消し → 買い物リストに戻る |
| **✅買ったよ** | 完了 → 履歴へ移動＋ポイント獲得 |
| **行をタップ** | 詳細を開く |

◯ の中身で担当者が分かります：**空** = 誰も宣言していない、**🛒** = 自分、**🦊など** = その人が買いに行く。

> 他の人が宣言した品でも「✅買ったよ」を押せます（「たろうさんが買いに行く予定です。買ったことにしますか？」と確認が出ます）。子どもが宣言して親が持ち帰った、というときに使えます。

### 行をタップして詳細

<img src="screenshots/05-detail.png" width="320" alt="詳細を開いたところ">

**写真**・メモ・予算・追加した人が見られ、ここから **💬コメント / ⭐よく買うものに登録 / ✏️編集 / ×削除** ができます。
写真を外すときは ✏️編集 →「✕ 写真を外す」。
よく使うボタンと削除を離すため、削除は詳細の中だけに置いています。

自分以外が追加したものは ✏️編集・×削除の代わりに **📝（メモ）** が出ます。名前や写真は追加者本人にしか
変えられませんが、「これで買ってきて」のような買う人への申し送りはメモとして誰でも追記できます。

## 4. ⚡ よく買うもの

<img src="screenshots/08-shortcuts.png" width="320" alt="よく買うもの">

**お買い物ページのフローティングボタン（⚡よく買う）**から開けます。登録・編集（削除・写真差し替え）・
新規登録のすべてをこのシートで行います。定番品を登録しておくと、**タップして確認するだけでリストに
追加**できます（項目数が増えて隣の項目に触れてしまいやすいため、確認をひとつ挟みます）。
カテゴリごとに並びます。写真・行き先を付けているものは、そのまま買い物リストにも引き継がれます。

**表示は「🖼️ カード」「☰ リスト」の2種類から選べます。** 既定はリスト（品名を詰めて一度にたくさん
見渡せる）。カードに切り替えると写真中心の表示になります。切り替えは端末ごとに覚えます。

**カード形式で、写真を付けられます。** 写真があると同じ商品でも型番違い・詰め替え用などを
一目で見分けられます。写真が無い項目のうち、アボカド・にんじん・鶏肉・牛乳など**よくある品名は
自動でそれっぽいイラストが出ます**（品名から連想しているだけで実際の写真ではないので、
編集モードからいつでも本物の写真に差し替えられます）。それ以外はプレースホルダーのアイコンです。

**登録の仕方は2つ**
1. 「⚡よく買う」シートの **＋ 新しく登録する**から入力する（写真も付けられます。カテゴリは[3章](#3--お買い物タブ)の追加と同じく必須です）
2. **買い物リストや履歴のカードにある ☆ をタップ**（メモ・予算・カテゴリごと登録されます。登録済みは⭐に変わります）

削除・編集は「✏️ 編集」を押したときだけできます（誤操作防止）。編集モード中は
カードの写真をタップすると **「写真をセットする」（撮影・ライブラリから選ぶ）と 🎨「イラストを選ぶ」を
別々に選べる**シートが開きます。自動で出るイラストが気に入らないときも、ここから115種の中の
別のイラストを能動的に選び直せます。

カード（写真以外の部分）をタップすると、**品名・カテゴリ・手間・予算・メモなどをまとめて直せる編集シート**が
開きます。カテゴリ必須化より前に登録していて**カテゴリが空のまま**の項目も、ここから選び直せます。

### 📦 ストックと自動で連動します

<img src="screenshots/18-shortcut-cycle.png" width="320" alt="よく買うもの登録時の買う間隔">

よく買うものを登録すると、**同じ名前のストック項目が無ければ自動で作られます**（🟢たっぷり）。
毎回別々に登録する手間がなくなり、[⏳ そろそろ切れるかも](#2--そろそろ切れるかも買い忘れ防止)の対象にもすぐなります。

登録シートからは、**買う間隔（任意）**も一緒に指定できます。品物によって
無くなるまでの期間はバラバラなので、ここで個別に設定しておくと、履歴が3回貯まるのを待たずに
その品専用のペースで知らせてくれます。すでに同じ名前のストックがある場合は、新規作成せず
その買う間隔だけ上書きします（在庫レベルはそのまま）。

> ☆ からの登録（上の2番目の方法）では買う間隔は指定できません。あとで
> ストックタブ → 品名をタップ → 買う間隔、から設定してください。

## 5. 💴 支出・家計

<img src="screenshots/19-expenses.png" width="320" alt="支出・家計タブ">

左上のアバター（プレイヤー情報）から開きます。完了件数と支出（💴を記録していれば実支出、無ければ予算合計）が見られます。

### その他の支出を記録

お使いリストを通さずに買ったもの（コンビニでの立て替えなど）も、金額だけ記録して集計に含められます。
**「＋ その他の支出を記録」**から。

- レシート写真を選ぶと、端末内で無料のOCR（文字認識）が金額を読み取り、
  金額欄に仮入力します。読み取り精度は完璧ではないため、**保存前に必ず金額を確認**してください
  （レシート写真自体は保存されません。金額を読み取るためだけに使います）
- OCRを使わず、金額を直接入力するだけでもOK
- 記録した分は一覧表示され、間違えたら×で削除できます

## 6. 🧾 購入完了済み履歴

<img src="screenshots/09-history.png" width="320" alt="購入完了済み履歴">

左上のアバター（プレイヤー情報）→「🛒買い物履歴」から開きます。

完了した買い物は一覧から消えて、ここに**日付ごと**（今日 / 昨日 / 7月28日(火)…）に貯まります。

- **❤️👏🎉 ありがとう** — 買ってくれた人にお礼を送れます（本人に通知が届きます）
- **💴 金額** — 実際に払った金額を記録できます。記録すると「💴 支出・家計」（[5章](#5--支出家計)）の集計が**実支出の集計**に変わります
- **↩️** — 間違えて完了にしたものを買い物リストに戻せます
- **☆** — よく買うものに登録

完了から90日経つと自動でアーカイブへ移り、動作が重くならないようにしています。

## 7. 🎯 ミッションタブ（ごほうび・ポイント）

<img src="screenshots/10-missions.png" width="320" alt="ミッションタブ">

右上（名前と？の間）の🏆ボタンから開きます。

### 🔥 連続記録と称号
おつかいを完了した日が連続すると記録が伸びます。累計回数で称号が上がります。
🌱見習い → 🚶配達員 → 🛒上手 → ⭐マスター → 👑達人（画面の一番上に**常に表示**）

その下は **⚡ウィークリー / 🎁ごほうび / 🎯ミッション** の3つに切り替えられます（縦に長くなりすぎないよう分けています）。

### ⚡ ウィークリーミッション（毎週月曜リセット）
**ふだんの行動で自動的に進みます。** 特別な操作は不要です。

| ミッション | 報酬 |
|---|---|
| 🛒 おつかいを3回完了する | +3pt |
| 🔥 急ぎのおつかいを1回完了する | +2pt |
| ❤️ ありがとうを3回送る | +1pt |

### 🎁 ごほうび
おつかい完了でポイントが貯まります（**ふつう1pt / 💪2pt / 💪💪3pt、🔥急ぎは+1pt**）。
貯めたポイントを、保護者が登録した「ごほうび」と交換できます。

- 保護者は「✏️ ごほうびを編集」から追加・削除できます（例: アイス 3pt）
- 交換すると家族に通知が届き、交換履歴に残ります
- ポイントが足りないごほうびは、ボタンが薄く表示されます

### 家族からのミッション
保護者が子どもに「〇〇を3回やったら300円」のようなミッションを出せます（ウィークリーとは別枠）。
**🎯ミッション**サブタブの**＋ 新しいミッション**から作成します（保護者のみ表示されます）。

## 8. 📦 ストックタブ

<img src="screenshots/11-stock.png" width="320" alt="ストックタブ">

家にある物の残量を記録しておく場所です。**丸をタップするたびに 🟢 → 🟡 → 🔴 → 🟢 と切り替わります。**

タブ上部の **⏳ そろそろ切れるかも** はアコーディオンになっていて、開くと
「何日前からお知らせするか」（知らせる時期）を選べます（→ [2章](#2--そろそろ切れるかも買い忘れ防止)）。

- 🟢 たっぷりある / 🟡 残り少ない / 🔴 切れてる
- **＋ 新しく登録する**から追加します。**カテゴリ（🍎食品／🧻日用品／📦その他）の選択は買い物リストと同じく必須**です。写真を付けられます（どれのことか一目で分かる）。実際に撮る/選ぶ以外に、🎨「イラストから選ぶ」も使えます
- 詳細シートの **⚙️ 詳細設定**（既定では閉じています）を開くと、カテゴリ・行き先・買う間隔を変更できます。カテゴリと行き先は**買い物リストに追加するときもそのまま引き継がれる**ので、未分類になりません（行き先は[設定タブ](#9-️-設定タブ)で1件以上登録してあるときだけ表示されます）
- 🟡🔴 にすると、**お買い物タブの「⏳ そろそろ切れるかも」に自動で出ます**
- 同じ名前のおつかいを**「✅買ったよ」で完了すると、🟡🔴のストックは自動で🟢たっぷりに戻ります**（手動で戻す必要はありません）
- 買い物履歴から周期が読める品には「🔄 約7日ごと・あと2日」と予測も表示されます
- タップして詳細から「🛒 買い物リストに追加」、**「買う間隔」の指定**ができます（→ [2章](#2--そろそろ切れるかも買い忘れ防止)）。写真を付けているものは、そのまま買い物リストの写真にも引き継がれます
- 詳細の「✏️ 写真を変更」から、登録後でも写真・イラストを差し替えられます
- 詳細の「✏️ 名前」から、登録後でも商品名を直せます（タイプミスの修正など）。ただし過去の購入履歴は旧名のままなので、買う間隔の学習は新しい名前で3回買うまでリセットされます
- 登録時に「何日ごとに買う？」を入れておくこともできます
- **[⚡よく買うもの](#4--よく買うもの)に登録すると、ここにも自動で追加されます**（同じ名前が無い場合のみ）

### 🛡️ メンバー管理（保護者のみ）

<img src="screenshots/13-member-admin.png" width="320" alt="メンバー管理">

誤操作を防ぐため、**「管理メニューを開く」を押したときだけ**操作できます。

- **家族から外す** — その人はデータを見られなくなります（**ログインアカウントは残ります**）。他のメンバーのログインアカウントそのものを削除する手段はありません
- 自分自身のアカウント削除は次項参照

### 👤 自分のアカウント削除

プロフィールカードの下部、**「アカウント削除メニューを開く」**の中にあります。
役割（保護者・副保護者・こども）を問わず、**本人だけが**いつでも削除できます
（他のメンバーのアカウントを保護者が代わりに削除することはできません）。
プロフィール・統計・ログイン情報が削除されます。**追加した依頼やコメントは家族の記録として残ります**。
自分が家族に残る唯一の保護者で、他にメンバーが残っている場合は削除できません
（先に別のメンバーを保護者にしてください）。
実行前に、確認のため半角英字で「delete」と入力する最終確認があります（元に戻せない操作のため）。

## 10. 🔔 通知

スマホを閉じていても届きます（設定 → 通知 →「通知をオンにする」で有効化）。

> ここは**利用者から見た通知の一覧**です。どの関数がどれを送っているかは
> [`functions/README.md`](../functions/README.md#含まれる関数10個) が正本。通知を足すときは両方直す。

| 指名されたとき | 「○○さんから『牛乳』を頼まれました」 | 指名された人だけ |
| 誰かが立候補したとき | 「○○さんが買いに行きます」 | 依頼した人 |
| 買ってきたとき | 「○○さんが買ってきました」 | 依頼した人 |
| ありがとうが届いたとき | 「○○さんからありがとう！」 | 買った人 |
| ごほうび交換したとき | 「○○さんがアイスと交換しました」 | 本人以外の家族 |

- 通知の時刻は設定タブから追加・削除できます（家族で共有・5分きざみ）
- 通知が要らない人は「通知をオフにする」で**その端末だけ**止められます

## 12. 困ったときは

| 症状 | 対処 |
|---|---|
| 新機能が出ていない | 設定 → 🔧メンテナンス → **⬇️ アプリを最新版に更新** |
| 表示が最新でない気がする | ホーム画面を**下に引っ張る**、または 🔄 データを再読み込み |
| 通知が来ない | 設定 → 通知 →「通知をオンにする」／端末の通知設定を確認。iPhoneは**ホーム画面に追加したアプリから**開く必要があります |
| データがおかしい | 設定 → 🔧メンテナンス → 🚪 強制ログアウト（家族のデータは消えません） |
| 家族に入れない | 招待コードは6文字（英大文字と数字）。保護者に再確認を |
| 写真だけ保存されない | 内容は保存されています。通信環境を確認して、✏️編集から選び直してください |
| ⏳ の予告が早すぎる・遅すぎる | ストック → ⏳そろそろ切れるかも → **知らせる時期**を変更 |
| ⏳ に出てくる周期がずれている | ストックタブで品名をタップ → **買う間隔**を手で指定（履歴の学習より優先されます） |
| 買ったばかりの品が ⏳ に出る | その品のストックを **🟢 たっぷり**に戻すと、そこが周期の起点になります |
| 上のどれにも当てはまらない・要望を伝えたい | 設定 → 📄その他 → **✉️ お問い合わせ**（ログイン画面の下のリンクからも開けます） |

## 13. ✉️ お問い合わせ

不具合の報告・機能の要望・その他の質問を、開発者に直接送れるフォームです（`contact.html`）。
ログインしていなくても使えます。

**開き方**（3か所、どれも別タブで開く）

| 場所 | 導線 |
|---|---|
| アプリ内 | 設定タブ → 📄 その他 → **✉️ お問い合わせ** |
| ログイン画面 | ログインカードの下の「使い方ガイド · **お問い合わせ**」リンク |
| プロジェクトハブ（`hub.html`） | フッターの「お問い合わせ」リンク |

画面下に固定の「← アプリに戻る」ボタンは、**スマホでアプリ内・ハブから開いたときだけ**出ます
（PC など幅768px以上の画面と、ログイン画面から開いたとき＝`?from=auth` 付きでは出さない。
フッターには「使い方ガイド」「プライバシーポリシー」へのリンクがあります）。

**入力項目**

| 項目 | 必須 | 備考 |
|---|---|---|
| お名前 | ✅ | |
| 会社名・組織名 | 任意 | |
| メールアドレス | ✅ | 形式チェックあり。返信先としてそのまま使われる |
| 電話番号 | 任意 | |
| 件名 | ✅ | 開発者に届くメールの件名になる（`【おうちのおつかい】件名`） |
| お問い合わせ内容 | ✅ | 最大4,000文字 |
| プライバシーポリシーに同意します | ✅ | チェックするまで送信ボタンが押せない。文中の「プライバシーポリシー」はリンク |

**送信の流れ**

1. 必須項目を埋めて同意にチェック → 「送信する」が押せるようになる
2. 押すと「送信しています…」→ 成功で「✅ 送信しました」（入力欄はクリアされる）／失敗で「⚠️ 送信に失敗しました」と、直接メールできるアドレスの案内が出る
3. 送信内容はサーバー（Cloud Functions の `submitContactForm`）が受け取り、**記録として保存**したうえで**開発者へメール通知**する。訪問者のメールアプリは開かない（一般的な企業サイトのフォームと同じ体験）
4. 空欄・メール形式の誤り・未同意はサーバー側でも弾かれる（画面のチェックを迂回されても通らない）

**できないこと・注意**

- 送信後に内容を編集・取り消しすることはできません（必要なら再送してください）
- 添付ファイルは送れません（スクリーンショット等が必要な場合は、返信メールに添付してください）
- 機械的な大量送信への対策（人には見えない項目を使った判定）が入っています。通常の利用には影響しません
- 入力内容の取り扱いは[プライバシーポリシー](https://b-w-hiroki.github.io/otsukai/privacy.html)「1. 取得する情報」に記載しています

> 開発者向け: 送信先の関数・メール通知の設定（Gmail アプリパスワード）は
> [`functions/README.md`](../functions/README.md#3-お問い合わせフォームのメール通知任意) を参照。
